# على الطريق – حزمة PWA أولية

هذه الحزمة هي نسخة الواجهة الأولية لتطبيق متابعة الطرق، مهيأة للتثبيت كتطبيق ويب تقدمي (PWA) وتعمل دون اتصال بعد أول تحميل.

## المحتويات
- `index.html`: واجهة التطبيق وإدارة محلية للمحافظات والمداخل والحالات.
- `manifest.webmanifest`: إعدادات التثبيت على الهاتف.
- `sw.js`: التخزين المؤقت والعمل دون اتصال.
- `icon.svg`: أيقونة التطبيق.

## تنبيه تقني مهم
هذه النسخة تحفظ البيانات داخل متصفح/جهاز المستخدم فقط. لا تتضمن بعد خادماً أو قاعدة بيانات مشتركة أو تسجيل دخول وصلاحيات مشرفين؛ لذلك لا يجوز اعتمادها كنظام عام لتحديث حالات الطرق بين عدة مستخدمين قبل إضافة backend آمن.

## النشر
تحتاج إلى استضافة HTTPS لملفات المجلد، ثم فتح الرابط في Chrome واختيار «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».
